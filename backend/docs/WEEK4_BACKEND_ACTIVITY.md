# 4주차 백엔드 작업 정리

- 담당: 현지민
- 브랜치: `week4-backend-integration`

## 작업 내용

### 1. 관리자 API 연동

기존 관리자 API의 호출 경로와 CORS 설정을 보완했습니다. 이후 최신 main의 Front 변경사항을 반영해 새로 추가된 입력 항목을 저장하고 조회할 수 있도록 수정했습니다.

- 과정: 소개, 학습 목표, 분야, 썸네일, 공개 상태, 입문·기초·응용 난이도
- 콘텐츠: 학습 목표, 업무 활용, 과정 내 순서, 검수 상태
- 실습: 제목, 안내, 예제 파일, 정답 결과, 결과 유형, 허용 오차, 핵심 함수, 정답 수식
- 퀴즈: 보기별 피드백, 작성 주체, 다시 볼 시점
- 연결 항목: 태그, 스킬, 여러 실무자료
- 자막: 구간별 시작·종료 시점과 문장

추가 항목을 수정하거나 지운 뒤 다시 조회했을 때 반영되는지도 테스트했습니다. 이전 버전의 과정 없는 초안도 열 수 있도록 기본값 처리를 추가했습니다.

### 2. 추가 관리자 기능과 로그인 연결

태그·동의어와 실무자료를 등록·수정하는 API, 콘텐츠 편집에 필요한 카탈로그 조회 API를 추가했습니다. 기존 관리자 로그인 쿠키와 CSRF 토큰을 그대로 사용하도록 연결했습니다.

최신 Front는 목업 모드로 고정되어 있어 환경 설정으로 API 모드를 선택할 수 있도록 수정했습니다. 관리자 기능이 같은 로그인 세션을 사용하도록 호출 코드와 Vite 프록시도 맞췄습니다.

### 3. 공개 범위와 입력 검증

콘텐츠 공개와 과정 공개를 분리했습니다. 공개된 과정의 공개 콘텐츠만 사용자 화면에 제공하며, 연결된 자료도 공개 상태인 것만 내려줍니다.

퀴즈 정답·보기별 피드백·실습 정답 결과와 수식은 공개 콘텐츠 응답에서 제외했습니다. 자막 시간, 다시 볼 시점, 실습 허용 오차와 연결 ID도 서버에서 검사하도록 보완했습니다.

### 4. 문서 정리

API 명세서에 최신 Front 기준 요청·응답, 필드와 상태값, 오류 코드를 반영했습니다. 서버 실행 방법, 환경 설정, 새 개발 DB의 테스트 계정과 연동 확인 순서도 정리했습니다.

- API 명세서: [ENDPOINTS.md](ENDPOINTS.md)
- 실행 방법·테스트 계정: [INTEGRATION_GUIDE.md](INTEGRATION_GUIDE.md)

초안 보조테이블은 변경이 필수가 아니라는 피드백에 따라 유지했습니다. DB 날짜 필드는 기존 명세를 확인해 누락 항목을 정리했으며, 추가 반영은 DB 담당자와 협의가 필요합니다.

## 확인 결과

| 항목 | 결과 |
|---|---|
| 백엔드 자동 테스트 | SQLite 환경에서 15개 통과 |
| 프론트 자동 테스트 | 26개 통과 |
| 프론트 빌드 | 통과 |
| 실제 MySQL 연동 | 로컬 DB 계정 인증 실패로 검증 미완료 |
| 실제 브라우저·MySQL 통합 확인 | 미완료 |

백엔드 테스트에는 추가 필드의 저장·재조회·삭제, 검수·입문 처리, 기존 로그인으로 태그·자료 관리, 잘못된 참조·자막 입력 거절, 공개 자료 필터와 정답 정보 차단이 포함됩니다.
