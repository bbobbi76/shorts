# 관리자와 사용자 화면

- `/`: 역할 선택
- `/admin/contents`, `/admin/courses`: 관리자 등록·수정·공개·비공개
- `/learn`, `/learn/courses/:id`, `/learn/contents/:id`: 사용자 공개 과정 탐색·영상 재생·자료 확인

예시 모드에서 공개 콘텐츠가 없으면 사용자 화면에 `화면 예시` 과정과 샘플 영상을 표시합니다. 실제 공개 콘텐츠가 생기면 샘플 대신 공개 콘텐츠를 보여줍니다. 이 예시는 서버 응답이나 관리자 저장 데이터에 포함되지 않습니다. 사용자 입장 후 관리자 경로 직접 접근은 차단됩니다. 관리자 메뉴의 사용자 화면 보기는 관리자 권한을 유지한 공개 화면 확인입니다.

사용자 목록·직접 조회·파일 조회는 공개 콘텐츠에 한정하며 정답·해설·관리자 상태를 응답에서 제외합니다. 학습 진도·퀴즈 제출·AI 피드백은 아직 연결하지 않았습니다. 실제 API 모드의 회원 인증·공개 자료 검사와 사용자 API 구현은 팀 서버 연동 후 확인해야 합니다.

검증: 자동 검사 18개·빌드 통과. Chromium에서 역할 선택→사용자 관리자 접근 차단→관리자 로그인→기존 콘텐츠 공개→사용자 영상 재생→비공개 전환→직접 조회 차단을 확인했습니다. 390px 사용자 영상 화면 넘침도 확인했습니다.
