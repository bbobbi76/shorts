# 프론트엔드 검증 기록

확인일: 2026년 10월 15일. Codex가 로컬 Windows·Chromium 환경에서 확인했습니다. 팀원 직접 확인 또는 실제 백엔드 완료를 의미하지 않습니다.

관리자·사용자 분리 후 자동 검사 **18개**와 빌드를 통과했습니다. 추가 검사·캡처와 실제 서버 미연동 범위는 [ROLES.md](ROLES.md)를 참고합니다.

관리자 화면 개선판은 기존 검사를 다시 실행했고 16개 통과·빌드 통과를 확인했습니다. 추가한 **390px·긴 제목/파일명·필드 오류 의미·키보드·대화상자·모바일 메뉴** 검증과 현재 페이지별 캡처는 [IMPROVEMENTS.md](IMPROVEMENTS.md)에 정리했습니다. 아래 360px 등은 초기 구현 때 확인한 기록입니다.

## 자동 검사

`npm.cmd test`: 16개 통과.

- 공개 필수값 누락, 퀴즈 정답 범위, 선택 파일 없이 공개 가능한 조건
- 지원하지 않는 확장자·빈 파일·용량 초과 거절
- 과정·콘텐츠 수정 및 조회 복원, 생성 중복 방지
- IndexedDB Blob 보존, 공개·비공개 전환
- 저장 실패 시 기존 저장값 보존, 업로드 실패 후 재시도
- 시연 세션 401·403
- 실제 API 어댑터의 쿠키·CSRF·Idempotency-Key·FormData
- HTTP 오류·잘못된 응답·네트워크 오류·타임아웃

`npm.cmd run build`: TypeScript 검사 및 Vite 프로덕션 빌드 통과.

패키지 설치 후 발견된 검사 도구 취약점은 해당 도구 버전을 올려 해결했습니다. 최종 npm audit 결과는 알려진 취약점 0건입니다.

## 브라우저 확인

- 과정 등록·수정 후 새로고침 복원
- 공개에 필요한 항목이 빠진 경우 누락 안내 및 요청 차단
- 실제 브라우저가 생성한 MP4·PNG 업로드와 파일 복원
- CSV 예제·텍스트 템플릿 첨부·미리보기 링크
- 퀴즈 정답·해설 미리보기
- 공개·비공개 상태 전환 및 재조회
- 저장 실패·재시도, 업로드 실패 시 기존 파일 보존, 동일 파일 재선택
- 로그인 만료·권한 없음 안내 후 편집값 유지
- 미저장 화면 이동 취소 후 입력 유지
- 제목 검색 빈 결과와 초기화
- 360·768·1440px 편집 화면, 360px 목록·과정 입력·미리보기 및 모바일 메뉴

검사 중 발견한 모바일 표의 가로 넘침은 숨김 라벨의 위치를 수정해 해결했습니다. 표 자체는 내부 가로 스크롤을 사용합니다.

## API 모드 확인 범위

별도 로컬 API 모드에서 **Playwright HTTP 응답 대체**로 화면과 요청 어댑터의 계약을 확인했습니다. 실제 백엔드 서버나 DB를 구현·연결한 검사가 아닙니다.

- 세션 응답·쿠키 요청·CSRF 헤더·초안 생성·저장 중 버튼 잠금
- API 재조회 후 화면 복원
- HTTP 503·401·403 처리 및 입력 유지, 재로그인 후 저장
- 실제 서버 미연결 시 오류 표시, 예시 데이터로 자동 전환하지 않음

검사에서 의도적으로 반환한 401·403·503과 서버 미연결 500은 브라우저 네트워크 오류 로그에 나타납니다. 정상 시연 모드의 마지막 화면에서는 콘솔 오류가 없음을 별도로 확인합니다.

## 남은 통합 확인

실제 팀 서버의 세션·쿠키·CSRF·권한 검사, 실제 미디어 검사와 저장소, DB 트랜잭션·중복 방지, 학습 기록 보존 정책, 서버 공개 상태와 사용자 화면 반영은 백엔드 연결 후 확인해야 합니다. 본 결과를 서비스 전체 구현 완료로 제출하지 않습니다.
