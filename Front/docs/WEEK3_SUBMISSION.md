# 3주차 과제 제출 내용 (프런트엔드)

## 개발 범위

4주 내 시연 가능한 관리자 콘텐츠 업로드 화면을 구현했습니다. 과정·콘텐츠 등록과 수정, 파일 첨부 및 미리보기, 퀴즈 입력, 공개 전 필수 항목 확인과 공개·비공개 전환을 지원합니다. 프런트엔드는 React·TypeScript·Vite를 사용했습니다.

현재는 브라우저 IndexedDB 예시 데이터로 동작하며 실제 백엔드·DB와 파일 저장소는 연결하지 않았습니다. 회원 관리, 사용자 학습 진도와 AI 피드백 등은 이번 범위에서 제외했습니다. 백엔드 및 DB 기술은 팀 협의 후 확정이 필요합니다.

## DB 명세 작성 참고

관리자 화면 기준으로 과정(`courses`), 콘텐츠(`contents`), 미디어(`media`) 정보가 필요합니다. 과정에는 과정명·설명·학습목표·직무·주제·난이도, 콘텐츠에는 과정 ID·제목·상태·퀴즈·실습 안내, 미디어에는 파일명·형식·종류·영상 길이·저장 위치를 둘 수 있습니다. 이는 화면 입력값에 기반한 초안이며 실제 DB 명세는 백엔드 담당자와 협의해야 합니다.

## 엔드포인트

프런트엔드 API 연결 계약 초안을 작성했습니다: [API_CONTRACT.md](API_CONTRACT.md). 과정·콘텐츠 조회와 저장, 공개·비공개 처리, 미디어 업로드·조회 경로를 제안했으며 실제 서버 구현이나 확정 명세는 아닙니다.

## 세부 기능

- 브라우저 File API와 HTML video 메타데이터로 파일 정보와 영상 길이를 확인합니다.
- `URL.createObjectURL`로 미리보기하고, 사용 후 `URL.revokeObjectURL`로 임시 주소를 해제합니다.
- 저장·업로드 실패 시 입력값을 유지하고 재시도할 수 있도록 했습니다.
- 로컬 시연 데이터는 IndexedDB에 저장하며 실제 서비스 DB와 구분됩니다.

## AI 사용 내역

Codex를 사용해 화면 구성과 React·TypeScript·CSS 코드, 로컬 시연 저장소와 API 연결 어댑터를 작성·수정했습니다. 공개 전 입력 검사, 오류·모바일 화면 개선, 검사와 제출 문서 작성에도 활용했습니다. 검사용 영상은 예시 파일이며, 학습자 대상 AI 피드백 기능은 구현하지 않았습니다.
