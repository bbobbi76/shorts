# 사용자 페이지 프론트 구현 기록

작업일: 2026-10-31. 작업 브랜치: `front`. 기준: `main`의 `704d067`을 fast-forward로 반영한 상태.

## 확인한 미구현 항목

기존 `/learn`은 입력한 질문과 관계없이 고정된 검색 결과를 보여줬고, `/learn/preview`의 영상·문제·AI 피드백도 화면 예시였다. 공개 과정·영상·자료 조회 API는 이미 있었으나 사용자 메뉴에서 과정 탐색으로 연결되지 않았고, 자막 구간 이동·이어보기·시청 기록·메모는 없었다.

현재 백엔드 `app.main`에는 AI 검색 라우터가 등록돼 있지 않다. 사용자 응답은 퀴즈·정답·실습 채점 기준을 제외하며, 사용자 답안 제출·AI 피드백·계정별 학습 기록 API도 제공하지 않는다. 이번 변경은 기존 공개 조회 계약과 프론트에서 처리 가능한 기능을 사용한다.

## 구현한 내용

- `/learn`: 공개 자료의 제목·학습 목표·활용 업무·과정명·자막 단어 검색, 과정·난이도 필터, 12개 단위 결과, 빈 결과·조회 오류·재시도. 검색 조건을 URL로 복원하며 자막 결과의 해당 시점으로 이동한다. AI 의미 검색으로 표시하지 않는다.
- `/learn/courses`: 공개 과정 검색과 과정별 영상 목록, 학습 목표, 로컬 시청 위치 표시. 공개 API에 이름이 없는 분야는 고정 ID로 추측해 표시하지 않는다.
- `/learn/contents/:id`: 실제 영상 재생, 공개 파일 URL 사용, 자막 VTT 트랙·구간 이동·자막 내 검색, 실습·자료 다운로드, 프롬프트 복사, 다음 영상과 과정 내 이동.
- 학습 메모: 5,000자까지 자동 저장하고 저장 실패 시 작성한 내용을 유지하며 안내한다. 실제 과제 제출이나 AI 채점으로 표시하지 않는다.
- `/learn/history`: 이 브라우저의 시청 위치·메모 복원, 개별·전체 삭제, 삭제 전 확인. 현재 공개된 콘텐츠에 한해서만 기록을 표시하며 비공개 기록도 전체 삭제할 수 있다.
- 영상 교체 시 이전 영상 위치·완료 상태를 초기화하고 메모는 보존한다. 시청 기록은 브라우저·데이터 모드·API 주소별로 분리하고 최근 100개까지 보관한다. 서버 진도·계정 기록으로 전송하지 않는다.
- 모바일 내비게이션·검색·학습 화면, 영상 영역에 맞춘 재생 화면, 키보드로 학습 자료·메모 탭 이동, 파일·저장소·네트워크 오류 안내를 보완했다.
- 기존 `/learn/preview`는 직접 접근 시 예시임을 안내하며 기존 목업 화면을 유지했다.

## 검증

- 자동 테스트: 5개 파일, 38개 테스트 통과. 신규 검증은 자막 검색·필터·공개 과정 범위, 잘못된 자막·재생 시점, VTT 이스케이프, 시청 기록과 메모 동시 보존·영상 교체·손상 데이터·저장 오류·삭제·기록 수 제한·모드 분리를 포함한다.
- TypeScript 검사 및 Vite 빌드 통과.
- `scripts/browser-learner.cjs`: 별도 목업 주소 5179에서 실제 브라우저의 검색·조건 복원·자막 이동·자막 검색·다운로드·메모 복원·이어보기·다음 영상·모바일·비공개 접근·기록 삭제/취소 검증. 화면 오류 없음.
- `scripts/browser-learner-api.cjs`: 별도 API 모드 주소 5180에서 HTTP 응답을 재현해 503 재시도·페이지 나누기·필터 조합·공개 미디어 URL·구간 이동·키보드 탭·저장 공간 오류·비공개 기록 제외·404·빈 목록·오프라인 시 목업 전환 없음 검증. 화면 오류 없음. 관리자·AI 경로 및 쓰기 요청 없음.
- 위 API 모드 오류 검증은 HTTP 응답을 가로채 재현한 계약 검증이다. 이후 실제 FastAPI·MySQL을 실행한 추가 검증은 아래와 같이 별도로 수행했다.
- QA 자료와 화면 캡처는 Git에서 제외한 `output/playwright/`에 보관한다. 기존 사용자 접속 주소의 데이터와 DB·접속 설정은 변경하지 않았다.

## 실제 백엔드 연결 검증

실제 FastAPI와 MySQL 테스트 복사본으로 사용자 화면을 검증했다. 원본 데이터는 변경하지 않았으며 접속 설정·DB 준비 및 보호를 위한 보조 파일은 이 프론트 변경에 포함하지 않는다.

- 실제 공개 과정·콘텐츠 조회, 단어·자막 검색, 과정 내 이동과 영상 재생 확인.
- 자막 구간 이동, 시청 위치 복원, 브라우저 메모 저장·복원 및 영상 종료 후 로컬 시청 완료 표시 확인.
- 실습 파일 다운로드와 실제 파일 내용 일치 확인. 영상 Range 요청은 `206`, 32바이트 응답 확인.
- 비공개 영상 상세와 파일은 `404`, 저장 요청은 조회 전용 게이트에서 `423`으로 차단.
- 실제 브라우저 API 응답 40건에서 서버 오류 없음, 화면 실행 오류 없음. 모바일 검색·과정·학습 기록 화면 넘침 없음.
- 원본 데이터·구조와 업로드 파일의 전후 보존 여부도 별도 로컬 검증에서 확인했다.

DB 복사본·접속 보조 파일·덤프·로그는 커밋에서 제외한다. 사용자 답안 제출·채점·AI 검색·서버 학습 기록까지 연결한 것으로 보고하지 않는다.

## 백엔드 연결이 남은 항목

AI 검색 라우터 통합과 실제 콘텐츠 ID·자막 인덱스·공개 여부 연동, 사용자 퀴즈·실습 제출 및 AI 피드백, 계정별 학습 기록 저장은 별도 연결이 필요하다. 현재 구현한 단어 검색과 로컬 시청 기록은 이 기능들의 완료를 의미하지 않는다.

관리자 분야·스킬 선택 목록과 통계·삭제·순서 변경은 이후 2026-11-01 프론트 작업에서 연결했다. 인증·테스트 범위는 [ADMIN_API_CONNECTIONS.md](ADMIN_API_CONNECTIONS.md)를 참고한다.
