# 3주차 프론트엔드 구현 현황

관리자 화면 개선판의 최신 변경·도구 확인·PC/390px 검증·페이지별 캡처는 [IMPROVEMENTS.md](IMPROVEMENTS.md)를 함께 제출합니다. AI 실제 사용 범위는 [AI_USAGE.md](AI_USAGE.md)에 추가했습니다.

## 구현한 부분

- 관리자 공통 메뉴와 로그인·권한 안내 화면
- 과정 목록·등록·수정
- 콘텐츠 목록, 제목 검색, 과정·공개 상태 필터
- 콘텐츠 초안 등록·수정, 과정·목표 입력
- 영상·썸네일·실습·템플릿 업로드와 파일 확인
- 퀴즈 문제·보기 2~4개·정답·해설 입력
- 현재 입력값 기반 영상·퀴즈·첨부 자료 미리보기
- 공개 필수값 검사와 공개·비공개 상태 전환
- 저장 중 버튼 잠금, 실패 시 입력 보존, 이탈 확인
- 로컬 브라우저 예시 데이터 저장과 실제 API 어댑터 분리

## 아직 완료되지 않은 부분

- 실제 팀 백엔드·DB 연결 및 서버 권한·파일 검증: 백엔드 담당자와 계약 합의 후 통합 확인 필요
- 사용자 홈·상황 검색·학습 진도·AI 피드백·마이스펙: 이번 관리자 작업 범위 밖
- 회원 관리, 분석 대시보드, 과정 내 영상 순서 편집: 이번 우선 범위 밖
- 공개 영상·퀴즈 변경 시 기존 학습 기록 보존 정책, 미사용 업로드 파일 정리: 서버 정책 필요
- 외부 배포: 진행하지 않음

## 과제 항목별 준비물

| 과제 | 프론트 담당 준비 |
|---|---|
| 1 개발 범위 | 위 구현·미완료 구분, React·TypeScript·Vite 사용 기록 |
| 2 DB 명세서 | 백엔드 담당 작성. 화면 입력 필드와 자료 연결 필요사항 공유 |
| 3 관리자 모듈 | 이 폴더의 소스, lock 파일, 실행 안내, 캡처 제출. node_modules·dist는 소스 제출에서 제외 가능 |
| 4 엔드포인트 | API_CONTRACT.md를 프론트 요구사항 초안으로 공유. 서버 구현 여부는 별도 표시 |
| 5 세부기능 | FEATURES.md의 실제 사용 기술·이유 정리 |
| AI 사용 | AI_USAGE.md를 확인하고 팀원 직접 검토 내용 추가 |

## 화면 캡처

`output/playwright/`의 콘텐츠 목록·과정 목록·과정 입력·공개 필수값 오류·학습 미리보기·콘텐츠 편집 화면을 첨부합니다. 후속 오류·모바일 캡처도 같은 폴더에 저장합니다. 화면에 표시된 QA 항목과 짧은 영상은 검사용 예시입니다. 실제 교육 콘텐츠 제작 완료나 백엔드 연동 완료의 근거로 사용하지 않습니다.

실제 검증 내역은 [VERIFICATION.md](VERIFICATION.md)를 참고합니다.
