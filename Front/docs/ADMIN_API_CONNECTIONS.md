# 관리자 추가 API 연결 기록

작업일: 2026-11-01. 작업 브랜치: `front`. 프론트 코드·문서만 수정했다.

## 연결한 기능

- 분야·스킬: UI 쿠키 인증 API로 서버 목록을 조회하고 과정 등록·수정·목록, 콘텐츠 스킬 연결, 실무자료 분야 선택에 사용한다. 고정 목록 밖의 ID도 서버 조회값으로 검증한다. 조회 실패 시 고정 목록으로 대체하지 않고 오류·재시도를 제공한다.
- 관리자 통계: 기존 대시보드 API의 회원·과정·콘텐츠·실무자료·태그 수, 최근 콘텐츠와 운영 로그를 표시한다. 새로고침과 조회 재시도를 제공한다. 과정 미지정 초안이 서버 통계에 포함되지 않는 점을 안내한다.
- 미공개 초안 삭제: 목록에서 삭제 확인·취소·중복 클릭 방지와 실패 안내를 제공한다. 삭제 성공 응답으로 목록을 갱신한다. 공개 이력 검사는 기존 서버가 수행한다.
- 영상 순서: 과정 목록의 영상 순서 링크에서 전체 콘텐츠를 읽고 위·아래 이동, 변경 취소, 일괄 저장·재조회, 미저장 이동 경고를 제공한다. 비공개와 초안을 포함한 과정 전체 ID를 보낸다. 실패 후 입력을 유지하고 재시도하거나 확인 후 서버 목록을 다시 읽을 수 있다.

## 관리자 인증

현재 백엔드는 기존 통계·삭제·순서 API와 UI API의 인증이 다르다. 프론트 로그인 한 번으로 같은 계정의 UI 쿠키 인증과 기존 Bearer 인증을 함께 수행한다. 비밀번호는 저장하지 않고 토큰만 API 주소별 탭 저장소에 보관한다. 브라우저 저장소가 막히면 탭 메모리에서만 사용하므로 새로고침 후 추가 로그인이 필요할 수 있다.

기존 API 요청 전에는 UI 세션을 다시 확인해 활성 관리자 권한을 검사한다. 보조 인증 실패 시 UI 로그인도 취소하며, 로그아웃 시 두 인증을 모두 해제한다. 서버 재시작으로 세션이 만료되면 재로그인한다. 실제 로그인·변경 기능 검증은 테스트 복사본에서 수행했다.

## 검증

- 자동 테스트 6개 파일 45개 통과. 인증 결합·부분 로그인 실패 정리·로그아웃·권한 재확인, 실제 API 경로·숫자 ID·순서 배열, 서버의 새 스킬 ID, 목업 순서 검증·공개 이력 삭제 제한을 추가했다.
- TypeScript 검사와 Vite 빌드 통과.
- 실제 FastAPI·MySQL 복사본: 잘못된 비밀번호 거절, 관리자 로그인·재로그인, DB에 추가한 분야·스킬 ID 99 선택·저장·새로고침 복원, 전체 순서 저장·복원·미저장 이동 취소, 삭제 취소·확정과 삭제 후 404, 공개 이력 삭제 거절, 서버 통계 수치·삭제 로그 표시, 모바일 통계 화면, 두 인증의 로그아웃 후 401을 확인했다.
- 실제 브라우저 API 응답 163건에서 서버 오류 없음, 화면 실행 오류 없음. 생성·정렬·삭제·로그인 테스트는 복사본에서만 수행했다.
- 기존 목업 브라우저 시나리오 `browser-workfit.cjs`와 API 오류 복구 시나리오 `browser-admin-recovery.cjs`도 통과했다. API 오류 복구 시나리오는 실제 MySQL이 아닌 HTTP 계약 재현이다.
- 원본 데이터·구조와 업로드 파일이 전후 동일함을 별도 로컬 검증에서 확인했다. 접속 설정·DB 덤프·보조 실행 파일은 커밋에서 제외한다.

## 기존 API의 범위

과정 미지정 UUID 초안은 기존 삭제 API가 지원하지 않아 삭제 대상에서 제외했다. 과정에 연결해 저장한 숫자 ID 콘텐츠의 삭제만 연결했다. 공개 이력이 있는 콘텐츠는 비공개로 전환해야 한다.

AI 검색의 백엔드 통합, 사용자 퀴즈·실습 제출·AI 피드백·계정별 학습 기록은 이 네 관리자 API 연결과 별개이며 구현 완료로 보고하지 않는다. 기존 서버의 Bearer 인증은 서버 메모리에 보관되는 개발용 토큰 구조를 그대로 사용한다.
