# 관리자 화면 디자인 기준

## 이번 개선 방향

기존 엑셀 숏폼 과정·콘텐츠 운영 흐름과 API 계약을 유지한다. 전체 재설계, Refine 전환, 외부 배포는 하지 않는다.

- 콘텐츠·과정 목록과 입력 폼을 우선한다. 장식용 통계 카드, 홍보 문구, 영어 보조 제목과 그림을 제거한다.
- 기존 초록색을 주요 작업 색상으로 유지하고 흰색 입력 영역과 중성 배경을 사용한다.
- 본문·입력·버튼은 14~16px, 보조 문구는 최소 12px, 페이지 제목은 26~28px로 정한다.
- 간격은 4px 단위로 적용한다. 입력은 44px 이상, 모바일 주요 버튼도 44px 이상으로 한다.
- 주요 버튼은 채운 초록색, 보조 버튼은 흰색 테두리, 위험·오류는 붉은 계열과 문구로 구분한다.
- 상태를 색상만으로 구분하지 않고 임시저장·공개·비공개 문구를 함께 표시한다.
- 오류 요약과 필드별 안내를 연결하고 오류 요약으로 포커스를 옮긴다. 입력 라벨, 도움말 연결, 필수·오류 의미, 키보드 포커스를 제공한다.
- 390px에서는 목록의 제목·과정·상태·수정 동작을 화면 안에 제공한다. 긴 제목·파일명은 줄바꿈하며 동작 버튼을 밀어내지 않는다.
- 미리보기·로그인·이탈 확인은 기존 기본 dialog를 개선해 사용한다. 키보드 포커스와 닫은 뒤 원래 위치 복원을 확인한다.

## 요청 도구 확인

현재 세션의 호출 가능한 도구, 로컬 스킬·패키지·설정, Plugin Management 검색으로 확인했다.

| 도구 | 확인한 상태 | 이번 작업 대안 |
|---|---|---|
| shadcn/ui MCP | 호출 가능한 MCP 없음. 플러그인 검색 결과 없음. 로컬 캐시에 shadcn 가이드 문서는 있으나 MCP 연결 증거가 아님 | 공식 Native Select·Table·컴포넌트 문서와 캐시 가이드를 참고하고 기존 select·table·dialog·입력을 재사용 |
| Impeccable | 호출 가능한 도구·등록된 스킬 없음. 플러그인 검색 결과 없음 | 정보 우선순위·글자·간격·대비·키보드·반응형·오류·빈 상태 직접 점검 |
| Hallmark | 호출 가능한 도구·등록된 스킬 없음. 플러그인 검색 결과 없음 | 초기 방향을 기존 관리자 목적·기획·색상과 비교 검토. 도구 실행으로 표현하지 않음 |

세 도구를 실행하거나 설치했다고 주장하지 않는다. 이번에는 새 UI 컴포넌트 라이브러리를 도입하지 않는다. 이 결과는 전체 설치 가능 여부를 단정하지 않으며 더 많은 플러그인은 제품 플러그인 디렉터리에서 확인할 수 있다.

[플러그인 디렉터리](https://chatgpt.com/plugins)에서 다른 설치 가능 항목을 확인할 수 있다.
