# 5주차 프론트엔드 작업 정리

작업 기간: 2026-10-27~28
담당 범위: 관리자 프론트엔드 보완, 기능별 소스 구조 정리, API 연동 시 화면 동작 검증
작업 브랜치: `front`

## 작업 개요

멘토 피드백에 따라 기존 관리자 화면에서 저장·오류·로그인 복구 흐름을 보완하고, 기능이 한 파일에 모여 있던 프론트 코드를 기능별 폴더로 분리했습니다. 기존 기능을 유지하면서 협업 시 수정할 위치를 쉽게 찾고, 실제 API를 사용할 때 입력 내용과 저장 상태가 일관되게 유지되도록 개선했습니다.

## 1. 기능별 폴더 구조 정리

- `features/admin/`: 로그인, 과정, 콘텐츠, 태그·실무자료, 미디어, 퀴즈 화면을 분리했습니다.
- `features/learner/`: 기존 사용자 화면과 학습 화면 예시를 모았습니다.
- `shared/`: 공통 입력 필드, 모달, 오류·로딩 표시와 표시 함수를 분리했습니다.
- `domain/`: 데이터 타입, 입력 검증, 공개 조건과 기존 브라우저 데이터 변환을 모았습니다.
- `data/api/`, `data/mock/`: 실제 API 요청과 IndexedDB 목업 저장소를 분리했습니다. 기존 브라우저 저장 데이터와 모드 선택 기능은 유지했습니다.

## 2. 관리자 화면 미비점 보완

- 저장하지 않은 변경사항이 있을 때 로그아웃 전 확인하도록 했습니다.
- 로그인 만료·권한 오류 후 다른 계정으로 다시 로그인해도 작성 중인 입력과 편집 경로를 유지하도록 했습니다.
- 과정 상세와 검색 태그·실무자료 조회 실패 시 다시 시도할 수 있도록 했습니다.
- 태그·자료 저장 응답을 현재 항목과 목록에 바로 반영하여, 저장 후 목록 조회 실패가 저장 실패처럼 보이지 않도록 했습니다.
- 자료 파일 업로드를 시작할 때부터 저장하지 않은 변경사항으로 표시해 화면 이동에 따른 입력 유실을 방지했습니다.
- 과정 등록의 중복 저장을 막고 과정명 필수 입력을 적용했습니다.

## 3. 콘텐츠 저장·공개 및 파일 표시 개선

- 신규 콘텐츠 저장 후 공개 요청만 실패해도 저장된 항목의 수정 화면에서 다시 시도하도록 했습니다.
- 과정 없이 저장한 초안을 과정에 연결하면서 서버 ID가 바뀌는 경우, 편집 주소도 새 ID로 갱신하도록 했습니다.
- 저장 전 공통 입력 검증을 적용하여 자막 시간, 다시 볼 시점, 실습 숫자 입력 등을 확인하도록 했습니다.
- 업로드 후에는 서버가 반환한 영상 정보를 우선 적용하고, 해상도 정보가 없을 때 잘못된 문자열을 표시하지 않도록 했습니다.
- API·목업 모드에 맞는 저장 안내를 표시하고, 사용자에게 보이려면 콘텐츠와 과정이 모두 공개되어야 함을 안내했습니다.

## 4. API 모드 및 문서 정리

관리자·태그·자료·사용자 조회가 설정에 따라 목업 또는 API 저장소를 사용하도록 구조를 정리했습니다. 관리자 기능은 같은 로그인 세션과 CSRF 토큰을 사용하며, 서버 오류가 발생해도 목업 데이터로 자동 전환하지 않습니다.

README의 이전 API 비활성화 설명을 현재 동작에 맞게 수정하고, 프론트가 사용하는 API 요청·응답·오류 처리와 새 폴더 구조를 문서화했습니다. 백엔드 구현이나 개인 접속 환경 변경은 이번 프론트 커밋의 작업 범위가 아닙니다.

## 5. 검증 결과

- 자동 테스트: **4개 파일, 27개 테스트 통과**.
- TypeScript 검사 및 Vite 빌드 통과.
- 목업 모드 브라우저 검증: 과정·콘텐츠·태그·자료 저장, 새로고침 복원, 미리보기, 공개 처리와 모바일 화면 확인.
- API 오류 재현 검증: 조회 재시도, 로그아웃 취소, 권한 오류 후 입력 보존, 공개 실패 복구와 중복 생성 방지 확인.
- 실제 API 브라우저 검증: 로그인, 업로드, 저장·재조회, 초안 ID 변경, 콘텐츠·과정 공개, 사용자 영상 재생·자료 다운로드, 비공개 접근 차단 확인.

## 남은 프론트 작업

사용자 페이지의 과정·영상·공개 자료 조회 흐름은 연동을 확인했지만, 사용자 기능 전체가 완성된 상태는 아닙니다. 검색, 퀴즈 풀이, AI 피드백, 학습 기록은 제공 API와 담당 범위를 맞춰 이어서 개발해야 합니다.

기존 AI 퀴즈 스튜디오와 일부 학습 화면은 목업입니다. 이번 작업에서 실제 AI 생성·채점·학습 기록 저장을 구현한 것으로 보고하지 않습니다. 분야·스킬 목록 조회 계약과 자막 파일 불러오기도 후속 확인·개선 항목입니다.
