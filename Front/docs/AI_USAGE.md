# AI 사용 내역

이번 관리자 프론트엔드 초안은 사용자의 요청과 첨부한 2주차 최종 기획을 바탕으로 Codex가 생성·수정했습니다.

| 사용 부분 | 실제 작업 |
|---|---|
| 화면 구성 | 관리자 메뉴, 과정·콘텐츠 목록, 등록·수정, 미리보기, 오류 안내 구성 |
| 코드 작성 | React·TypeScript·CSS, 로컬 IndexedDB 시연 저장소, API 요청 어댑터 작성 |
| 기능 검토 | 공개 전 필수 항목, 업로드 실패, 로그인 만료, 저장 중 중복 클릭 및 입력 유지 처리 |
| 검증 | 자동 검사 작성·실행, 브라우저 시나리오 실행·화면 확인·캡처, 발견된 오류 수정 |
| 제출 문서 | 실행 방법, API 연결 계약 제안, 세부기능 설명, 구현 현황 초안 작성 |
| 검사 미디어 | 브라우저 Canvas·MediaRecorder로 QA용 짧은 MP4·썸네일 생성. 실제 교육용 영상이 아님 |

사용자의 직접 검토·수정이 완료되었다고 가정하지 않았습니다. 팀원은 제출 전 화면을 실행하고 API 계약·제한값·실제 담당 범위를 검토하여 이 문서를 갱신해야 합니다.

이 문서는 **개발 과정에서의 AI 사용**을 설명합니다. 서비스 안에서 학습자의 퀴즈·실습을 분석하는 AI 기능은 이번 관리자 프론트엔드에 구현하지 않았습니다.

## 관리자 화면 개선 작업

Codex가 기존 React 코드, API 어댑터와 2주차 최종 기획을 읽고 다음 부분을 개선했습니다.

- 정보 우선순위·글자 크기·대비·간격·버튼의 디자인 규칙을 정리하고 CSS를 수정했습니다.
- 장식용 통계·영어 제목·홍보 문구를 줄이고 과정·콘텐츠 목록을 운영용 표로 정리했습니다.
- 공개 필수값의 필드별 오류, 도움말 연결, 오류 요약 포커스를 작성했습니다.
- 대화상자 이름·닫기 후 포커스 복원, 모바일 메뉴 키보드 이동·Escape·비활성 처리를 보완했습니다.
- 긴 제목·파일명과 390px 모바일 목록·폼을 점검하고 발견한 배치 문제를 수정했습니다.
- 기존 자동 검사와 실제 브라우저 시나리오를 실행하고, 실제 API 모드의 HTTP 응답 대체 검사를 수행했습니다. 실제 팀 서버·DB 통합 검사를 했다고 표현하지 않습니다.
- 변경 내역·디자인 기준·검증 결과·캡처 문서를 작성했습니다.

shadcn/ui MCP·Impeccable·Hallmark는 현재 세션에서 연결된 도구를 찾지 못해 **실행하지 않았습니다**. 도구 검색, 캐시의 shadcn 가이드와 공식 문서 확인, 기존 HTML 컴포넌트 개선으로 대체했습니다. UI 라이브러리 추가, Refine 전환, 외부 배포는 하지 않았습니다.

팀원의 직접 검토·승인이 완료되었다고 가정하지 않았습니다. 제출 전 실제 담당자가 결과를 확인하고 직접 수정·검토한 내용을 추가해야 합니다.

## 관리자·사용자 분리

Codex를 사용해 역할 선택 화면, 별도 사용자 경로·과정 탐색·영상 재생·자료 확인을 작성했습니다. 기존 관리자 기능을 유지하고 공개 데이터 조회·파일 접근을 별도 어댑터로 분리했으며 비공개 직접 접근 차단과 사용자 역할의 관리자 변경 차단을 검사했습니다. 사용자용 API 계약은 제안 단계이며 실제 팀 서버의 회원 인증을 구현한 것으로 표현하지 않습니다.

## 자연어 검색·과제·AI 피드백 화면 목업

Codex로 `LearningPreview.tsx`와 `learning-preview.css`를 작성하고 사용자 진입 화면에 연결했습니다. 자연어 질문 입력, 예시 영상 결과, 학습 영상 영역, 실습 답안 입력, 객관식 문제 선택, AI 피드백 예시 표시를 구성했습니다. 실제 검색·영상 스트리밍·과제 제출·채점·AI 호출·학습 기록 저장은 구현하지 않았습니다. 새 화면은 서버 요청과 별도로 React 상태와 고정된 예시 문구만 사용합니다. 로컬 브라우저에서 검색 화면→학습 화면 이동, 실습·문제 탭과 예시 피드백 표시를 확인하고 캡처했습니다. 개인 제출 문서는 프로젝트 루트의 `WEEK3_SUBMISSION.md`에 로컬로 저장했습니다.

## 관리자 AI 퀴즈 화면 목업

Codex를 활용해 참고 파일 선택·제거, 참고 텍스트와 생성 요청 입력, 문항 수·난이도 설정, 고정된 퀴즈 예시 추가, 문제·보기·정답·해설 수정, 개별·전체 삭제와 삭제 복원 화면을 작성했습니다. 파일 이름과 크기만 브라우저 상태로 표시하며 파일 내용 읽기·서버 전송·AI 호출·DB 저장은 하지 않습니다. 생성 문항은 미리 작성된 엑셀 예시이며 기존 콘텐츠 퀴즈 저장과 분리되어 있습니다.
